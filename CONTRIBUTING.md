# Contributing to GitHub Repository Search UI

We welcome contributions! By contributing to this project, you agree to abide by our code of conduct.

## How to Contribute

1. Fork the repository.
2. Clone your fork:
   ```bash
   git clone https://github.com/your-username/github-repository-search-ui.git
   cd github-repository-search-ui
   ```

3. Create a new branch for your feature or bug fix:
   ```bash
   git checkout -b feature/your-feature-name
   ```

4. Make your changes and commit them:
   ```bash
   git add .
   git commit -m "Add your feature"
   ```

5. Push your branch to your fork:
   ```bash
   git push origin feature/your-feature-name
   ```

6. Open a pull request on GitHub.

## Code Style

Please follow the coding style used in the project. We use ESLint and Prettier to enforce code quality and consistency.

## Testing

Please ensure that your changes are covered by tests. Run the tests using:
```bash
npm test
```
